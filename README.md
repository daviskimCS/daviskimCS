# Davis Kim

**Software & Controls Engineer** at [Sorenson Engineering](https://www.sorensoneng.com/) — I build systems where the software has to move real hardware correctly the first time.

Most days that means deterministic control on 1 ms scan cycles, machine vision, and robot motion. I own the software for a vision-guided robotic part palletizer now running in production across five machines, built a TwinCAT Vision part-orientation classifier at 100% accuracy on its validation set, and designed the TwinSAFE/FSoE functional-safety architecture tying two machines' E-Stops to a single safety controller. Off the clock I write full-stack web software and bare-metal firmware.

B.S. Computer Science, UC Riverside.
